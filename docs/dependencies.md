# Registro delle dipendenze

Principio VIII della constitution: ogni dipendenza ha una data di review registrata in un file
versionato. `pnpm deps:check` (in CI) fallisce se un pacchetto di `package.json` manca da questa
tabella o ha una data non valida, e avvisa se l'ultima review risale a più di 12 mesi fa.

**Come si aggiorna**: quando aggiungi un pacchetto, aggiungi una riga con motivo e data. Quando
rivedi o aggiorni un pacchetto (anche con una PR di Dependabot), aggiorna versione e data. Il
controllo non confronta le versioni, così le PR di Dependabot non rompono la CI.

**Script di build ignorati**: pnpm 10 non esegue gli script di install delle dipendenze. `esbuild`
e `unrs-resolver` sono in `pnpm.ignoredBuiltDependencies` perché i loro binari arrivano come
dipendenze opzionali già compilate; `onlyBuiltDependencies` resta quindi vuoto (R-17).
